# 公共发布清单

这份清单用于检查代码、文档和研究结果是否适合进入公共仓库。未完成的项目应明确标记状态，不能用已脱敏代替实际核验。

## A. 仓库内容

- [x] README 说明项目范围、当前功能和研究边界。
- [x] 源代码、测试和文档不依赖本机绝对路径。
- [x] 公开仓库不包含私有 archive 的原始策略文本、交易记录和数据导出物。
- [ ] 新增 Markdown、脚本和示例继续检查路径、邮箱、手机号、token、API key、密码和账号。
- [ ] 新增 Notebook 时清除不必要的输出、执行计数和环境路径。

## B. 二进制文件和元数据

- [ ] 检查新增 XLS/XLSX 文件的 creator、lastModifiedBy、自定义属性、批注和隐藏工作表。
- [ ] 检查新增 PNG、WEBP 等图片的 EXIF、软件标记和注释。
- [ ] 不提交原始压缩包，或任何可以反推出个人、账户和数据供应商信息的导出物。

## C. 代码与自动化检查

- [x] 测试覆盖事件字段校验、成交假设、收益路径和公共 API。
- [x] CI 运行 pytest、compileall 和 Ruff。
- [x] 文档通过 MkDocs strict 构建。
- [ ] 新增公共 API 同步更新测试、README 和 API 文档。
- [ ] 引入外部依赖时补充版本范围、用途和许可证检查。

## D. 版权、来源和数据

- [ ] 核实第三方策略、论文附件、研报和数据导出物的再分发许可。
- [x] 第三方资料以来源链接和书目信息为主，不复制不必要的完整正文或原始附件。
- [x] 研究文档区分学术证据、研报线索和本项目尚未验证的研究假设。
- [ ] 公开派生统计时记录数据来源、处理步骤、时间范围和授权条件。

## E. 研究表达

- [x] 区分信号收益、回测收益、可成交收益和实盘收益。
- [x] 记录信号时点、下单时点、首次可成交时点、成交概率、滑点、费用和排队成本。
- [x] 分开主板 10%、创业板或科创板 20%、ST 及制度改革前后样本。
- [x] 使用滚动样本外验证、时间隔离和多重检验控制，不随机打乱交易日期。
- [x] README 明确说明资料仅供研究，不构成投资建议。
